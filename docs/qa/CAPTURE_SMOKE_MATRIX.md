# Capture Smoke Matrix

Manual smoke matrix for capture and intake flows.

## Coverage
- [ ] Offline photo capture starts while disconnected and queues work safely.
- [ ] Reconnect upload flushes queued capture items after connectivity returns.
- [ ] Watched-folder or DSLR intake lands files in the expected library path.
- [ ] Provenance is recorded for captured/imported assets.
- [ ] Citation links remain correct after capture/import completes.
- [ ] No backend at launch shows a clear degraded-state path instead of silent failure.

## Evidence
- [ ] Record device/platform used for capture.
- [ ] Record whether the path was offline, reconnect, or watched-folder/DSLR.
- [ ] Record the imported document ids or filenames checked for provenance/citation.
