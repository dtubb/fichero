# Appendix C: Keyboard Shortcuts

> 🤖 *AI Drafted (Not reviewed)*


The shortcuts that exist today. The list will grow; menus show the current shortcut next to each command.

• Switching sidebar modes: Control–Command plus a number key — for example, ⌃⌘1 for Library. Not every number is assigned; check the View menu for the current set.

• Reading layouts: ⌘0 (content only), ⌘1 (standard, side by side), ⌘2 (widescreen, stacked).

• Flipping renditions: ↑ and ↓ switch between a page's alternative images (original, enhanced, and so on).

• The standard Mac shortcuts work where you expect them: ⌘N (new), ⌘O (open), ⌘F (find), ⌘A (select all in the focused view), ⌘W (close window), ⌘, (Settings).
