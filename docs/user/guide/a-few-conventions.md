### A Few Conventions

You do not have to read this manual from cover to cover. If you are new to Fichero, the early chapters read well in order: they install the app, walk you through the window, and get your first materials into a library. But once you are working, the manual is meant to be dipped into. When you reach the point in a project where you want to transcribe a difficult hand, extract an index of people and places, correct a misread name, or search across everything you have gathered, turn to the part that covers that task and read only what you need. The parts above are arranged roughly in the order a real project unfolds, but nothing stops you from jumping ahead to the one that matters to you today.

A few conventions run through the manual. Some chapters carry a short note that they were drafted with the help of AI and are still being reviewed; where you see it, read the page as a good-faith description of the app that may yet be refined. 

Screenshots show Fichero as it looks, in the  version it was taken with, and your own windows may differ as the app evolves. 

Keyboard shortcuts are written with the usual Mac symbols:

⌘ for Command

⌃ for Control

 ⌥ for Option

⇧ for Shift

Thus, ⌃⌘1, for example, means holding Control and Command together while pressing the number one. 

Menu paths are written step by step, as in **Settings ▸ AI ▸ Models & Providers**.

This manual describes what Fichero does. Fichero is under active development, and features that are still settling; because the app changes from release to release, so will these pages. If something here does not match what you see on screen, trust the application, and expect the manual to catch up.

And if you would rather not read at all, and simply want to see what Fichero can do, install the app, drag a folder of scans or PDFs onto the sidebar, select a few pages, and run one of the ready-made transcription workflows. Importing, reading, running a workflow, correcting what comes out, is  the heart of Fichero.
