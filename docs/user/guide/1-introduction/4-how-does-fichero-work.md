### How does Fichero Work?

Under the hood, Fichero is an app which has two parts. First, a front-end, user-facing app, which is a native app for Apple devices written in SwiftUI, Apple's frameworks for writing apps. Second, a back-end server written in Python. The server, which comes bundled with the app, handles storage, search, workflows, and knowledge-graph processing. Fichero is thus both a fully native Mac, iOS, and iPad app, and an app which uses many of the same Python tools powering AI applications, websites, and services. (That is, Fichero is built on open source tools like FastAPI, DuckDB, LanceDB, LangChain, and LangGraph, but with an easy-to-use interface.) There is an iPad and iPhon eversion, which lets you connect to your Mac library.

Fichero is fast, capable, and model-agnostic. With it, you can chain together tools and workflows that are powered by AI models. These models can either run locally, for free, on your computer, where your data never leaves your computer. Or they can run in the cloud, using closed or open-source models, from many AI providers. You can thus use Apple's Foundation models for free, or you can get yourself an API key with one of dozens of AI providers, and use any powerful open source model, including ones from Anthropic, OpenAI, and other providers. (If you have a powerful enough computer you can even run such models locally, for free, using MLX, Ollama, LM Studio, and other comparable endpoints.)
