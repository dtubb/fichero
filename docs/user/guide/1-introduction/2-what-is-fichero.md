## What is Fichero

Fichero is a document library app, with AI workflows. It is an open-source place to keep track of primary and secondary sources: scanned archives, PDFs, field notes, historical documents, interview transcripts. You can import your sources, read them, extract structured information from them, annotate them, and work with them. It was developed to make it easy to navigate large and complex archives, using AI as a tool to assist in transcribing historical images and extracting useful structured data. Using Fichero, you can read source documents and process them with AI workflows, while always being able to see the sources. Fichero is an app for Apple devices, with a server built using open source tools. It is primarily a macOS app, with iPhone and iPad companion apps. It is open source.
