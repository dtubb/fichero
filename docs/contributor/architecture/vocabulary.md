# Shared Vocabulary

Use these terms in backend, frontend, API, and documentation names. A concept
has one name; `kg` is the only sanctioned backend abbreviation.

| Concept | Canonical term | Notes |
| --- | --- | --- |
| Grouping container | collection | Replace `folder` when naming new concepts. |
| 2D spatial view | canvas | `mind-palace` is legacy route terminology. |
| 3D spatial view | space | The shipped 3D view. |
| Knowledge graph | knowledge graph | Backend may use `kg`; Swift uses `KnowledgeGraph` or `KG`. |
| Scheduled work | automation | A schedule or trigger is an automation member. |
| API wrapper | service | `*ServiceGenerated.swift` is hand-written despite its suffix. |
| Library item | retired | Audit CLI-only endpoints before extending this term. |

Keep these aligned terms unchanged: document, artifact, annotation, claim,
entity, citation, note, activity, workflow, chain, batch, bookmark, provider,
and search.
