# Fichero Documentation

This folder contains the website of Fichero, which is the documentation for [Fichero](../README.md), [`../fichero/README.md`](../fichero/README.md)].  [‘Index.md’](../index.md) is hte front page of the documentation and the website at https://www.tubb.ca/apps/fichero. This folder also contains the [Fichero User Manual](), the Fichero [Reference Manual](../reference_manual/README.md), and the Fichero Contributor Manual() [README.md](contributor_manual/README.md). 

## Where to start?

Start with the**[What is Fichero?]('../user_manual/guide/Part I. Getting Started/1-introduction/3-what-is-fichero.md)**, then turn the the **[User Guide](user/README.md)** on how to install Fichero, and add, read, and use it to work with sources. It was predomaaintly written by Daniel Tubb.

The [Reference Manual]( ../reference_manual/) contains an index of the app, its different user interface elements, keyboard shortcuts, import and export formats. Much of this material is generated programmatically from the apps source code, or was written and edited by a LLM Coding Agent. (Mostly Anthropic’s Claude)

The **[Contributor Guide](contributor/README.md)** is about also written for mostly by AI, and contains instructions on how to contribute to the Fichero project and its architecture.

- **[Contributors](contributors.md)** is about the people who have contributed in different ways to making or testing Ficheros.
