Fichero Shell Mockups

Interactive device mockups — open in Safari to explore the navigation.
One set of zones, adapting to each device class.

Core idea: Fichero has five zones — Sidebar · Library · Preview · Reader · Inspector. On Mac, all five are visible at once in a persistent 3-column shell. On iPad, two are shown at a time in pairs. On iPhone, one fills the screen and you swipe through the stack. On visionOS, each zone is an independent window you place freely in space. The same zones, the same modes, the same data — just rearranged by what the device can show at once.

Device mockups

🖥
Mac
All 5 zones · 3-column persistent shell
Sidebar | Library/Content | Inspector. Modes swap content only — frame never moves. Zoned toolbar, glass sidebar + inspector, opaque reading surface.
⌘1–9 · ⌃⌘S · ⌃⌘I · ↑↓ navigate
📱
iPad
2 zones at a time · sidebar overlays
Pairs: Library+Preview · Reader+Preview · Reader+Inspector. Sidebar swipes in as an overlay — never eats a column. Width = two zones max.
Tap state buttons to switch pairs
📱
iPhone
1 zone at a time · swipe stack
Sidebar → Library → Reader → Inspector as a horizontal swipe stack. Inspector also slides up as a sheet from the Reader. Back button + arrow keys.
← → arrow keys or swipe
📺
Apple TV
Browse → Library → Reader
Focus-engine navigation, big text, remote-driven. Read-centric: the library is a launch pad for the reader, not a primary workspace.
← → arrow keys · focus nav
🥽
visionOS
Each zone = independent window
Sidebar, Library, Preview, Reader, Inspector each as a separate glass window you drag and place in space. No single-window constraint. Reader expands large; ornament bar floats below.
Drag windows · ornament toggles
