To *link* a [source](../Source.md) is to leave the file or folder where it already lives on your disk, and have Fichero point to it. Here, nothing is duplicated, and your files and folders stay wherever you arranged them. Fichero will keep track of the linked source. If you delete the original, or if it gets moved, or if Fichero loses access to it, then the source will stop working in Fichero. Linking is the default way to import a source, and means that your original files will not be moved or changed.
