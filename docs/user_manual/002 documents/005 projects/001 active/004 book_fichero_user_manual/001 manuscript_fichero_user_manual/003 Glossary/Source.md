A *source* is any item you add to your library. It might be an image, a PDF, a Word document, a scanned page, a folder of images, or an audio file. Everything in the library sidebar is a source, and sources are what you read, transcribe, annotate, and draw claims from. Fichero can import a source in different ways. It can *copy* a source into the library, or *link* to one where it already lives on your disk. Either way it indexes the contents (*e.g.*, text, transcription, metadata) so the source is searchable and can be connected to the rest of your work. A source can be one of many *import formats*.
