To *import* a [source](../Source.md) is to add it to your *project*. When you import, you choose how Fichero should keep track of the file. Fichero can [*link*](Link.md) to a source, leaving the original file on the file system or the internet; it can [*copy*](Copy.md) it into your Fichero *project*; Fichero can [*move*](Move.md) it into the project; or Fichero can [*sync*](Sync.md) with the original file. When you move a source into the project, the original file is moved into the Fichero project. The choice of importing is an option in the settings window. However a source is added to a Fichero project, Fichero will keep track of it, and allow you work with the source.
