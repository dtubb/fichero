To *copy* a [source](../Source.md) is to copy (or duplicate) the file and it in your project folder. This will lave your original it was. The library then holds its own copy, so the source keeps working whatever happens to the file you imported from. On a Mac APFS file system, the default file system on all Apple Silicon Macs, such a copy costs no disk space, because the file is cloned than duplicated.
