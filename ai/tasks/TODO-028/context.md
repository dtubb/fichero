## Background
The ingest module is a core component of Fichero that handles file import, metadata extraction, and storage. Currently lacks comprehensive documentation for developers and users.

## What you need to know

- Two ingestion modes: LINK (bookmarks) and COPY (APFS cloning)
- Extracts metadata and can optionally extract text content

- Documentation will help developers understand and use the ingest API properly
