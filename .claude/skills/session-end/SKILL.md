# Session End — Fichero

Wrap up so the next session starts informed. Don't ask permission — just do it.

## 1. Summarize the Session

Review what was accomplished:
- What was built, fixed, or refactored?
- What decisions were made?
- What was left incomplete?
- What problems or surprises were encountered?

## 2. Update MEMORY.md

Add durable knowledge only — things that will matter next session and beyond:
- New conventions discovered
- Decisions made (and why)
- Problems solved and how
- Environment facts that changed
- Do NOT add session-specific details — only lasting knowledge

Use targeted edits. Never rewrite MEMORY.md from scratch.

## 3. Update STATE.md

Update these sections:
- **Current Branch** — if it changed
- **This Week's Focus** — if priorities shifted
- **In Progress** — what's active right now
- **Blocked** — any new blockers
- **Next Session — Start Here** — clear entry point for next time (what to do first, what to check)

## 4. Update TASKS.md

Move completed tasks to done. Add newly discovered tasks.

## 5. Check for Commits

If there are uncommitted changes, ask: should these be committed before ending?

## Constraints

- Don't commit without asking
- Don't push without explicit approval
- Keep STATE.md Next Session concise — 3-5 bullet points max
- MEMORY.md gets durable lessons, STATE.md gets current navigation
