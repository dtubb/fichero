# ADDENDUM — Sunday evening, after the release

## The release shipped, and three things nearly stopped it

**`2026.08.02` is published on all three tracks**: DMG notarized + stapled +
GitHub release, Mac TestFlight, iPhone/iPad TestFlight, Sparkle appcast pushed.

Three failures on the way, all worth recording:

1. **`awk` aborted the release twice**, at the Mach-O signing filter.
   `find … -exec file {} +` echoes bytes from the paths it inspects; the
   embedded engine ships names that are not valid UTF-8; under a UTF-8 locale
   awk ABORTS. `LC_ALL=C` fixes it.

   **I got the sweep wrong.** I found the pattern, fixed the two `awk` sites I
   recognised, and stopped. The third — a `grep`, in the App Store re-sign —
   killed the TestFlight leg. A check written afterwards
   (`check_locale_safe_binary_pipes`) enumerated by STRUCTURE rather than by
   pattern and found a **fifth** site nobody had seen. The class is now swept
   by machine and the sixth instance is impossible.

2. **The size ratchet stopped the release at +1.9MB** — correctly. Traced to
   `anyascii`'s 2.5M transliteration tables, accepted deliberately with the

   surfaced the real problem: **the DMG had been built mid-afternoon and did
   not match main.** Had it succeeded, the artifact tagged `2026.08.02` would

- **A dead `pytest_collection_modifyitems`.** The hook was defined THREE times

- **`# noqa: F811 — extends prior hook`.** F811 is the redefinition rule. It
