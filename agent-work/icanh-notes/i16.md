## What's inconsistent (rationalization)
Across the shipped presets the same concepts are expressed differently for no reason, which makes the set feel unreliable and forces per-workflow fiddling.

Observed inconsistencies (verified in `resources/default_workflows/*.json`):
- **vision_mode**: Catalogue's transcribe uses `"auto"`; the default Transcribe uses `"llm"`; Auto-Detect mixes `"auto"` (typescript) and `"llm"` (others). No documented reason; determines whether Apple Vision is even reachable.
- **language**: some nodes `"en"`, some `"auto"`, review passes `"auto"` — inconsistent defaults for the same field.
- **provider aliasing**: extract/cleanup nodes use `$small`/`$medium`/`$large` aliases; transcribe nodes set no provider at all and rely on a fallback that excludes Apple (see milestone #8). Vision nodes have no tier alias convention.
- **naming**: "Transcribe" (file `transcribe_cloud`), "Transcribe Typescript", "Spanish Paleography (18th–19th C.)" vs "Transcribe Paleography" — file name, display name, and behavior don't line up; descriptions don't say "use this when…".
- **per-page output contract**: only some presets actually fan out per page (default Transcribe, Catalogue) while others (Auto-Detect) do not — same nominal output, different real behavior.

## Fix sketch (one convention)
- Define a shared base config for transcription nodes (vision_mode, language, a vision-tier provider alias e.g. `$vision`) and have every transcribe-family preset inherit it.
- Standardize display-name pattern: `Transcribe — <Profile>`; every preset description starts with "Use this when …".
- Make per-page fan-out an invariant every transcription preset must satisfy (tie to milestone #14 test).
- Pick one default for `language` (`auto`) and one for `vision_mode` (`auto`, so Apple is reachable) unless a preset has a documented reason to override.

## Test / acceptance
A contract test over `resources/default_workflows/*.json` asserting: every transcription node sets vision_mode/language from the shared convention, every transcribe-family preset's source→transcribe edge qualifies for per-page fan-out, and display names match the `Transcribe — <Profile>` pattern.
