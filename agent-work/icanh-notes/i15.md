## What's confusing / redundant (rationalization)
The shipped preset set has **10 transcribe-family workflows**, several of which overlap heavily. Users can't tell which to pick, and the Spanish/paleography space is triplicated. This is a top driver of the "I have to fiddle every time" feeling.

Current transcribe-family presets:
- `transcribe_cloud.json` → "Transcribe" (cloud LLM, per-page fan-out — the working default)
- `transcribe_auto_detect.json` → "Transcribe (Auto-Detect)" (classify+route; currently broken per-page, see milestone #1)
- `transcribe_typescript.json` → "Transcribe Typescript" (Apple Vision)
- `transcribe_manuscript.json` → "Transcribe Manuscript"
- `transcribe_htr.json` → "Transcribe HTR" (2-pass)
- `transcribe_paleography.json` → "Transcribe Paleography" (2-pass)
- `paleography_spanish.json` → "Spanish Paleography (18th–19th C.)"
- `transcribe_spanish_script_multipass.json` → "Transcribe Spanish Script (19th-20th C., Multi-Pass)"
- `transcribe_spanish_script_v2_child.json` → child sub-workflow
- `transcribe_spanish_script_v2_subworkflow.json` → "Transcribe Spanish Script v2 (Sub-Workflow)"

## Proposed keep / merge / retire (proposal only — do not delete)
| Preset | Action | Rationale |
|---|---|---|
| Transcribe (transcribe_cloud) | **KEEP** as canonical default | works, per-page, provider-agnostic |
| Transcribe (Auto-Detect) | **KEEP** after fixing #1–#3 | the one "smart" entry point; should subsume the per-script variants |
| Transcribe Typescript | KEEP (or fold into Auto-Detect's typescript branch) | only real differtypescript Apple-Vision path |
| Transcribe Manuscript / HTR / Paleography | **MERGE** into Auto-Detect's routed branches | identical to the branches Auto-Detect already routes to; standalone copies duplicate the prompts |
| Spanish Paleography (18th–19th) vs Transcribe Paleography | **MERGE** — one paleography profile parameterised by language | two paleography presets differ only in language hint |
| Spanish Script Multi-Pass vs v2 Sub-Workflow vs v2 Child | **RETIRE two, keep one** | three presets for the same 19th–20th C. Spanish hand; pick the sub-workflow form, retire the flat multipass + expose child only as a reusable component |

## Canonical target set (transcribe family)
1. **Transcribe** (default, cloud/Apple via runtime model picker, per-page)
2. **Transcribe (Auto-Detect)** (routes to typescript / manuscript / historical handwriting / paleography internally)
3. **Transcribe — Historical (2-pass)** (HTR+paleography merged, language param)
4. one reusable **Spanish Script** sub-workflow component (not a top-level "pick me")
