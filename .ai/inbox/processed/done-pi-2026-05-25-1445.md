# Fix #971 — NER loses context when text spans a page break

## What was done

Implemented overlap context in `fichero-engine/src/fichero/workflows/tools/extractors.py` to handle NER across page boundaries. When entity names or quotes span PDF page boundaries, the extractor now prepends context from the previous chunk.

## Implementation details

- **Location**: `_run_extractor()` → `_extract_chunk(chunk_text, chunk_idx)`
- **Overlap size**: 200 characters from previous chunk
- **How it works**: Before extracting each page/chunk, the last 200 chars of the previous chunk are prepended to provide full context for entities that span boundaries
- **Example**: "Juan" at end of page 1 + "Pérez" at start of page 2 are both visible when extracting page 2
